明确发现：屏幕与音频共用 GPIO39
图纸中未见 LCD 屏幕电路或接口。
main/boards/lichuang-dev/lichuang_dev_board.cc:91 设置 LCD DC = GPIO39。
main/boards/lichuang-dev/config.h:14 设置 I2S BCLK = GPIO39，与原理图一致。
板型构造函数仍无条件调用 InitializeSpi() 和 InitializeSt7789Display()。
因此当前固件对同一引脚配置了两个用途；即使没有连接屏幕，仍会执行屏幕初始化。
应先确认实物是否有另外的屏幕板，再移除遗留屏幕代码或按实际连接重新适配。
当前记录不预断具体板上故障表现。

待确认：NFC 串口方向与连接器
FPC2/H2：图中 TX2 = GPIO11，RX2 = GPIO12。
固件第二版 PN532：ESP32 TX = GPIO12，ESP32 RX = GPIO11，115200 baud。
两者 TX/RX 命名方向相反，但原图未画出 PN532 模块端，不能仅凭网名判定接错。
需要确认网名按主板还是外设方向命名，以及 PN532 实际连接 FPC2/H2 的线序。
FPC1：图中 TX1 = GPIO18，RX1 = GPIO17；不能与 FPC2/H2 混用。
图中连接器标号 TX1/TX2 不等同于固件 UART_NUM_1/UART_NUM_2 外设编号。

其他待核对项
1. 图中 POWER_OFF 接 GPIO45；当前板型代码没有对应的软件关机控制。
   这不等同于硬件按键不能开关机，图中另有 GEK100_33 电源按键电路。
2. TYPE-C 图注明确写着不给主板供电和充电，烧录时需接电池；
   但同一页又把 USB 的 VBUS-5V 网名接到 TP4056 的 VCC。
   图注与连线存在不一致，实际供电/充电路径应按实物核实。
3. 本页未明确展示云台电机/舵机驱动电路；外接控制板与串口用途需另行确认。

建议后续先核实实物屏幕和串口线序，再做固件适配与板上音频、NFC、电池测试。
